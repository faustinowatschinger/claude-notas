01Qué es un mod

Claude Code deja sumarle mods: apps propias que viven adentro de Claude, en un panel al costado del chat. Se instalan como plugins y quedan en todos tus chats.

Estos dos trabajan sobre los archivos .md de la carpeta donde abrís Claude. No hay base de datos aparte ni sincronización: lo que escribís o tildás queda en el archivo, y Claude lee y edita esos mismos archivos. Vos y Claude trabajan sobre lo mismo.

Lo que trae /notas

  • Explorador como el de VS Code: en cada carpeta, ＋📄 crea un archivo y ＋📁 una carpeta.
  • Editor dentro del panel, con menú / para títulos, listas, casillas, tablas y código.
  • [[enlaces]] entre notas, con la lista de las que la enlazan al pie.
  • Buscador 🔍 por nombre, ruta o dentro del texto.
  • Propiedades, #etiquetas, índice y plantillas, como en Obsidian.
  • Nota rápida: escribís, «Guardar», y queda como archivo.

Lo que trae /agenda

  • La lista del día, que le pedís a Claude que te arme en un archivo por día.
  • Un mes arriba: los días con archivo en color. Tocás un día y ves su agenda.
  • Las casillas - [ ] se tildan con un clic. Si empiezan con una hora en negrita, destaca el bloque que toca ahora.

02Lo que necesitás

Mac, Windows o Linux

Cada sistema usa lo suyo para copiar, pegar y la Papelera. En Linux: wl-clipboard o xclip.

Claude Code de escritorio

La pestaña Code de la app de Claude, versión 2.1.328 o más nueva. Necesita un plan pago: Claude Code no viene en el gratis. El Pro, de USD 20 por mes, alcanza.

03Instalalo en 3 comandos

Escribilos en el chat de Claude Code, uno por uno.

1

Sumá el catálogo

›/plugin marketplace add faustinowatschinger/claude-notas
2

Instalá las notas

›/plugin install notas@claude-notas
3

Instalá la agenda

›/plugin install agenda@claude-notas
✓

Abrí un chat nuevo. Los paneles se abren solos. Si no los ves, escribí /notas o /agenda.

TIP  Desde la terminal es lo mismo con claude plugin marketplace add … y claude plugin install ….

Plantillas

Cualquier .md de la carpeta de plantillas sirve. Al crear un archivo se reemplazan {{fecha}}, {{hora}} y {{titulo}}.

Un día de la agenda

Pedíselo a Claude: «Armame la agenda de hoy en dias/, un bloque por línea, con la hora en negrita y casillas.» Queda así:

# Día — 2026-11-20 - [ ] **10:00–12:30** Llamadas - [ ] **14:00–16:00** Grabar el reel - [ ] Guion - [ ] **18:00** Entrenar

06Cuidados que tiene

  • Nunca guarda un archivo con contenido como vacío.
  • Antes de la primera escritura de cada edición copia el original a ~/.claude/notas-versiones/.
  • Eliminar manda a la Papelera del sistema: se recupera desde ahí.

07Lo que todavía no hace

  • El puntero no cambia a la barrita de texto en el editor: al pasar el mouse se subraya la letra donde va a caer el clic.
  • En la app de escritorio, un clic en un link dentro del texto lo abre la app: los [[enlaces]] se navegan con los botones del pie.
  • No hay deshacer ni doble clic para seleccionar una palabra.
  • El editor abre archivos de hasta 90.000 caracteres.
  • Probado en Mac; en Windows y Linux, con tests simulados. Si el clic cae corrido una letra, el número a tocar es CORRIMIENTO en notas/hooks/editor.tsx.

09Armá el tuyo

Estos dos los escribió Claude. La app que uses todos los días se le puede pedir igual: Claude Code ya sabe armar mods.

1

Contale qué querés ver al costado del chat.

›Armame un mod con un panel que muestre mis pendientes y me deje tildarlos
2

Dejá que lo active. Claude lo escribe, lo prueba y la app te pregunta si querés activar los mods de esa sesión. Con un sí, el panel aparece al terminar la respuesta.

3

Pedile los cambios hablando: «el botón más arriba», «que se guarde solo», «que se vea bien en un panel angosto». Cada cambio se recarga al terminar la respuesta.

OJO  Los mods no corren aislados: leen y escriben archivos y corren comandos con tus permisos. Instalá los que puedas leer. El código de estos dos está abierto en el repo.
